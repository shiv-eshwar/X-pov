# XProv-MAS Springer SVMult package

This package is built from the supplied `Springer-Template-latex/author/authorsample.tex` template. It uses the matching `svmult.cls` class, `graybox` layout, Springer fonts, and `spmpsci.bst` bibliography style.

## Overleaf

1. Download the ZIP and upload it to a new Overleaf project.
2. Set `main.tex` as the main document if Overleaf does not select it automatically.
3. Compile with the default LaTeX setting. The included `main.pdf` is a preview of the verified 12-page build.
4. Replace the placeholder affiliation and email in `main.tex` before submission.

The supplied class is the Springer SVMult contributed-volume/chapter template, so the paper is intentionally typeset in its single-column book-chapter layout rather than the newer `sn-jnl` journal layout. Figures and the bibliography are included locally, so no external files are required.
